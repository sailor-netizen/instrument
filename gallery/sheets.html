Direction sheets — where each theme started

Five hand-written pages, same content in every one, each committed hard to a single idea and free to ignore this library entirely. That freedom is the point: a sheet can change the composition, which a token swap can never do. Every theme in the system began as one of these. Read DIRECTIONS.md for the vocabulary that makes a direction specifiable before anyone builds it.
